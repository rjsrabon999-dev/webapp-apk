বিল্ড করার উপায়:
১) এই ZIP এক্সট্র্যাক্ট করে সব ফাইল (".github" ফোল্ডারসহ) একটি Public GitHub রিপোতে আপলোড করুন।
২) রিপোর Settings > Actions > General > Workflow permissions এ "Read and write permissions" দিন।
৩) Actions ট্যাব > "Build APK" > Run workflow চাপুন।
৪) বিল্ড শেষ হলে Releases সেকশন থেকে webapp.apk ডাউনলোড করুন।

অথবা Android Studio-তে এই ফোল্ডার খুলে Build > Build APK(s) চালান।
